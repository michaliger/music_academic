# בדיקה ידנית לפני הגשה (כ-10 דקות)

לפני שמתחילים: שרת ה-backend רץ (`npm run dev`), האתר רץ (`npm run dev` בתיקיית frontend), ובטרמינל של ה-backend רואים `AI: gemini`.

## 1. בדיקה אוטומטית של השרת (דקה אחת)
בטרמינל חדש, בתיקיית `backend`:
```
npm run smoke
```
כל שורה צריכה להתחיל ב-✓. אם שורה מתחילה ב-✗, מה שכתוב לידה הוא הסיבה.
כדי לכלול גם את בדיקת האדמין (ב-PowerShell):
```
$env:ADMIN_PHONE="הטלפון שלך"; $env:ADMIN_PASSWORD="הסיסמה שלך"; npm run smoke
```

## 2. מה בודקים בעין באתר
סמני V אחרי כל שלב.

- [ ] **הרשמה**: שם, טלפון, אימייל וסיסמה. נכנסים לדף הבית.
- [ ] **דף הבית**: הרקע הסגול מכסה את כל המסך גם מאחורי הסרגל. הפסנתר ברוחב מלא ומנגן.
- [ ] **מוזיקת רקע**: לוחצים להפעלה, והיא נעצרת כשעוברים לדף אחר.
- [ ] **מפת הלימוד**: נפתחת עם כל תשעת הקורסים.
- [ ] **שיעור**: נפתח, הדוגמאות מתנגנות והפסנתר מאיר את התווים.
- [ ] **בוחן**: עונים, רואים הסבר אחרי כל תשובה, ובסוף יש קונפטי.
- [ ] **ספרייה**: בוחרים אקורד וסולם והמקלדת זזה.
- [ ] **תרגול**: המקלדת גדולה, והשאלות באימון השמיעה נראות בלי לגלול.
- [ ] **שאלי את המורה**: בוחרים נושא, שואלים, והתשובה מוצגת מסודר. בטרמינל מופיעה `AI answered`.
- [ ] **היסטוריה**: השאלה שנשאלה מופיעה ב"ההיסטוריה שלי".
- [ ] **אקורדים לשיר**: שיר חדש, מדביקים מילים, שומרים. לוחצים על מילה, בוחרים אקורד, והוא מתנגן ומקבל בדיקה. שומרים ופותחים לצפייה.
- [ ] **חברות**: מוסיפים מייל של משתמשת קיימת. מייל שלא קיים מציג את אפשרויות ההזמנה (Gmail, וואטסאפ, העתקה).
- [ ] **אדמין**: נכנסים עם משתמש האדמין, רואים משתמשים, מחפשים, ופותחים היסטוריית שאלות.
- [ ] **נייד**: מקטינים את החלון, או פותחים בטלפון, ובודקים שאין גלילה לצדדים.
